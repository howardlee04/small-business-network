# small-business-network
CCNA small business network portfolio project

## Project Overview
This project is a small business network designed in Cisco Packet Tracer.
The goal of this project is to demonstrate core networking concepts including VLANs, routing, DHCP, NAT, ACLs, and network troubleshooting.
The network will simulate a small business environment with separate networks for employees, servers, guest users, IoT devices, and network management.

## Project Goals
- Design a small business network topology
- Create and configure VLANs
- Configure trunk links
- Configure inter-VLAN routing
- Configure DHCP
- Configure static routing and/or OSPF
- Configure NAT
- Configure ACLs for traffic control
- Test network connectivity
- Troubleshoot intentionally created network problems
